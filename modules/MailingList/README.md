# Mailing list

Le module **Mailing list** permet d'envoyer des campagnes d'e-mails (newsletters, convocations, informations aux élus…) depuis l'intranet, sans passer par un outil externe.

## Carnets d'adresses et contacts

Rangez vos destinataires dans des **carnets d'adresses**. Un même contact peut figurer dans plusieurs carnets. Un carnet peut être :

- **privé** : vous seul le voyez ;
- **partagé** avec des collègues, en lecture seule ou avec droit de modification ;
- **public** : tous les utilisateurs de l'intranet peuvent l'utiliser pour leurs envois.

Les contacts peuvent être **importés** depuis un fichier et **exportés en Excel**. Quand vous saisissez l'adresse e-mail d'un contact, les adresses des agents de l'intranet vous sont proposées automatiquement.

## Expéditeurs

Chaque campagne part au nom d'un **expéditeur** : un nom et une adresse @marche.be, @ac.marche.be ou @cpas.marche.be, avec un logo en en-tête et un pied de page. Un bouton permet de vérifier que la configuration d'envoi de l'expéditeur fonctionne.

## Campagnes

Rédigez votre message avec un éditeur de texte riche (images, mise en forme) et ajoutez des pièces jointes. Choisissez ensuite les destinataires : un ou plusieurs carnets d'adresses, et/ou des contacts individuels. Le sujet de l'e-mail s'affiche en titre au-dessus du contenu.

Avant l'envoi, vous pouvez vous **envoyer un aperçu** pour voir le rendu exact. Les envois sont ensuite étalés dans le temps pour ne pas surcharger le serveur de messagerie. Vous suivez la progression de l'envoi destinataire par destinataire.

## Nouveau : les signatures sont intégrées au module

La gestion des **signatures e-mail**, auparavant séparée, fait désormais partie de la Mailing list. Vous la trouvez directement dans le menu du module.

Et surtout, **vous pouvez maintenant avoir plusieurs signatures**. Une signature reprend votre nom, votre fonction, votre service, vos coordonnées, le site web et un logo. Vous pouvez par exemple en créer une pour votre service et une autre pour une fonction particulière.

Chaque signature peut être :

- **associée à un expéditeur** : elle est alors ajoutée automatiquement sous chaque e-mail envoyé en son nom ;
- **copiée** ou **téléchargée en HTML**, pour l'utiliser aussi dans votre logiciel de messagerie habituel (Outlook, Thunderbird…).
